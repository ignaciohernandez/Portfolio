# Portfolio Profesional - Ignacio Hernández

Práctica Formativa 1 (PFO 1) - IFTS 16 Frontend

## Descripción
Portfolio web personal desarrollado con HTML5, CSS3 y JavaScript. Presenta información profesional, experiencia laboral, educación, habilidades técnicas y proyectos de GitHub.

## Tecnologías utilizadas
- HTML5 (etiquetas semánticas: `<main>`, `<article>`, `<section>`, `<nav>`, `<footer>`)
- CSS3 (variables, flexbox, grid, responsive design, dark/light mode)
- JavaScript (typing effect, filtros, animaciones, service worker)
- Google Fonts (Inter + JetBrains Mono)

## Requisitos de la consigna (PFO 1)
- [x] `<head>` con `<meta>`, `<title>`, `<link>` (CSS externo)
- [x] `<h1>`, `<p>`, `<a>`
- [x] `<img>` (foto del CV)
- [x] `<table>` (tecnologías que conozco, quiero conocer y hobbies)
- [x] `<form>` (nombre, apellido, email, teléfono, submit)
- [x] `<div>` y etiquetas semánticas HTML5
- [x] CSS externo con ids, clases, `font-family`, colores, backgrounds, height/width, bordes personalizados
- [x] Al menos 4 comentarios con anotaciones de mejoras
- [x] Código limpio e indentado

## Cómo verlo localmente
1. Clonar o descargar el repositorio.
2. Abrir `index.html` en el navegador.
3. O usar un servidor local:
   ```bash
   python -m http.server 8000
   ```
   Luego abrir `http://localhost:8000`.

## Deploy
- **Netlify Drop:** Arrastrar la carpeta a https://app.netlify.com/drop
- **GitHub Pages:** Subir a un repo público y activar Pages en Settings.
